# German translation style

- Address the user consistently with informal singular **du/dein**.
- Use concise labels and natural German sentences rather than literal English
  word order.
- Prefer established terms: *Sicherung*, *Zeitplan*, *Einbindung*, *Knoten*,
  *Zwei-Faktor-Authentifizierung*, and *Startkonfiguration*.
- Keep product names and protocol names unchanged: Pterodactyl, Wings, SFTP,
  API, Docker, MariaDB, Redis, and WebSocket.
- Preserve variables and interpolation placeholders exactly.
- Do not translate server names, filenames, shell commands, environment
  variables, mount paths, egg names/descriptions, or console output.
- Use typographic German quotation marks only in prose, never around values the
  user must copy literally.
- Avoid gendered role nouns where a neutral formulation is clear.
- Keep technical terms unambiguous in every locale: *Arbeitsspeicher*,
  *Speicherplatz*, *CPU-Auslastung*, *Port*, *Host*, *Egg*, and *Pterodactyl*.
- Regional variants may use dialect in controls, headings, and reviewed whole
  sentences. Never regionalize long technical prose word by word; fall back to
  clean Standard German until a complete native-speaker revision is available.
